npm packages in the web page llama-server.exe carries
=====================================================

llama-server.exe carries a web page, index.html, bundle.js, bundle.css and
loading.html, built from llama.cpp's tools/ui. Listed: every package whose
code the build kept in bundle.js, every package bundle.css was built from a
style or font file of, and the bundler, whose own helper modules are in
bundle.js. Each line gives the package's name, version and licence field,
then the licence files it ships, by the number of the text below.

Generated by `node tools/derive-notice.mjs --webui <llama.cpp checkout>` from
tools/ui at llama.cpp commit 9a532ae4bab1b164052ce60a738f78538b421c66,
whose package-lock.json has sha256
78e154a375fdd13f32a6f0f5bc73be3b45801a89f3fcf2774707ebb03a2e183d,
built with Node v22.22.3. Each of the four files that build wrote occurs
whole in the server this file describes,
llama-server.exe (sha256 0323cc4d64d5e2b2644b7589ea2175ee3551a7e591613be40b998179f8a5ec2b),
and a check fails when the llama-server.exe beside it differs. Line endings
are written as LF; the words are the files' own.

128 packages, 54 distinct licence texts.
