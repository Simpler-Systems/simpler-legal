# Licence texts the Windows installer carries

The Windows installer carries this folder, with this product's `LICENSE`, `NOTICE` and
`THIRD_PARTY_NOTICES.md`, beside the app, in a folder named `licenses` (the `resources` map in
`app/src-tauri/tauri.conf.json`). The files below concern the third-party software the
installer carries: the llama.cpp build it installs as `llama\` and the Node.js runtime it
installs as `node.exe`, which a clone of this repository does not carry; the Rust crates,
npm packages and Microsoft WebView2 loader the app itself is compiled from; and the NSIS
parts the setup program is made of. All but one are licence texts. `msvc-runtime.txt` is a
note on the three Microsoft files that come with no licence text, the Visual C++ runtime. The
product itself is Apache-2.0 (`../LICENSE`).

Each file is a byte copy of the file named in its Source column, at the tag, commit or
version named there, with these exceptions, each stated in its own row: `msvc-runtime.txt`
was written for this repository; `rust-crates.txt`, `npm-packages.txt` and
`llama.cpp-webui-npm-packages.txt` are generated; and `NSIS-COPYING.txt` has had its line
endings converted. `tools/derive-notice.mjs` recomputes every sha256 in the table, fails on
a file in this folder the table does not list, and fails when the installer configuration
stops carrying this folder or the licence page.

The llama.cpp texts other than its own `LICENSE` are the ones build 9222 embeds in
`llama-common.dll` (titles "License for jsonhpp", "License for cpp-httplib" and "License for
BoringSSL"); the two MIT texts are byte-identical to the upstream files named above. The
server and its libraries are 22 of the 43 files in llama.cpp's own release zip,
`llama-b9222-bin-win-vulkan-x64.zip` (sha256
`71d896955c0ae3576f6fd147f4ca197aa6a839ed7693651c14fe74014cef954e`), each byte-identical to
the zip's copy; the zip carries no licence file of its own. The zip also holds a
`libomp140.x86_64.dll`, which is Microsoft's build and is not shipped (`msvc-runtime.txt`,
section 2). The folder's `libomp140.x86_64.dll` is the LLVM project's OpenMP runtime from
conda-forge instead (`llvm-openmp-LICENSE.txt`). Three more files in the folder, the Visual
C++ runtime, are not in the zip; they were added from Visual Studio 2022 Build Tools
(`msvc-runtime.txt`). A folder filled by `tools/fetch-deps.mjs` also holds llama.cpp's
`LICENSE` at tag b9222.

llama.cpp also compiles in three single-file libraries that ask for no notice:
`stb_image.h` and `miniaudio.h` (into `mtmd.dll`) and `subprocess.h` (into
`llama-server.exe`). Each is dedicated to the public domain under the Unlicense, stb_image
with MIT and miniaudio with MIT No Attribution as the alternative licence, so no text of
theirs is included here.
